OpenYoumiya API 始终作为二创社区的基础设施无偿开放。只要在文档规定的频次限制内，所有人都可以免费调用。

但作为一个纯粹由社区爱好者自费发起并维护的项目，保障高可用输出的背后，是一笔非常现实且持续的硬性支出——包括服务器扩容、高带宽流量费用、数据库备份托管、监控审计以及日常高强度的考据维护成本。

世界总在变幻，感动的保质期或许无法预测，但只要我们还爱着，就想在能付出的时候，尽可能让这份关于二偶最美好的记忆、最真挚的热爱，超越时间的限制，在这片数据宇宙里走得更远。

数据库托管、备份、监控和日常维护等运行成本目前由维护者和社区赞助共同承担。

如果 OpenYoumiya API 曾对你的项目有所帮助，欢迎通过以下渠道为我们的服务器注入能量。每一笔支持，都是维持这个虚拟舞台永不停机、健康续航的燃料。
