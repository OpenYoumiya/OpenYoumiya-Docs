OpenYoumiya API 始终致力于构建一个开放、合规且富有活力的二创开发者生态。我们通过开源协议保障数据的自由流动，同时通过合理的规则维护平台的整体稳定。

本平台所提供的公开数据，除另有特别声明外，均默认采用 [Creative Commons Attribution 4.0 International License（CC BY 4.0）](https://creativecommons.org/licenses/by/4.0/)（知识共享-署名 4.0 国际许可协议）进行授权。

在完整遵守本协议规定的“署名要求”与“API 使用规范”的前提下，你可以将获取的公开数据用于个人、社区、学术研究甚至商业化项目，并允许对其进行复制、缓存、再分发、改编或派生。

## 署名规范

为了促进生态的良性循环并尊重维护者的劳动成果，当你在任何项目中使用 OpenYoumiya 的公开数据时，必须在应用内、文档、关于页面或数据来源列表中，引入清晰可见的版权署名。

我们推荐并鼓励使用以下格式：

- 纯文本格式（Text）:

```Plaintext
Data provided by OpenYoumiya API (https://openapi.youmiya.love)
```

- Markdown格式:

```md
Data Source: [OpenYoumiya API](https://openapi.youmiya.love)
```

- HTML 格式：

```html
Data Source: <a href="https://openapi.youmiya.love" target="_blank" rel="noopener noreferrer">OpenYoumiya API</a>
```

⚠️ 派生数据说明：如果你对 OpenYoumiya 原始公开数据进行了清洗、结构重组、合并或大幅度派生修改，请在署名时明确说明“该数据基于 OpenYoumiya 原始数据加工/修改而成”，以避免对后续使用者造成数据源层面的误导。

## 授权与免责范围

- **适用边界**：本协议所授予的权利仅适用于 OpenYoumiya API 正式返回的结构化公开数据。
- **第三方权利限制**：本协议不包含亦不代表授予任何第三方的商标权、角色版权、音乐版权、出演者肖像权、官方活动品牌或任何版权方/事务所的专有权利。OpenYoumiya 仅作为公开事实数据的整合与同步渠道，不对第三方知识产权提供任何形式的背书。
- **未发布数据保护**：主站 OpenYoumiya 内部及尚未通过公开 API 终端发布的私有来源记录、日志或后台数据，不属于“公开数据”范畴，不适用本协议。

## API 使用与流控规范

OpenYoumiya API 是一项由社区爱好者无偿发起并维护的开源项目。由于所有服务器、带宽及流量成本均由项目团队全额自费承担，为了保障共享资源的公平高可用性，并让这个项目能健康、长久地走下去，请所有客户端共同遵守以下“不滥用”原则：

- **频次限制（Rate Limiting）**：请严格在各接口文档规定的频次阈值内进行调用。客户端应主动建立本地缓存（Cache）机制，避免对静态或低频更新的数据进行高并发的重复请求。
- **安全凭证安全**：客户端应妥善保管自身的 API Token，禁止将其硬编码至公开的客户端源码（如前端 JS、开源仓库等）中，以防 Token 被恶意盗刷导致项目方产生额外的流量账单。
- **恶意行为判定**：禁止任何形式的恶意并发、爬虫轮询、或通过多账号绕过频次限制的行为。针对可能危及平台整体运行与经济负担的异常请求，系统网关将自动触发防御拦截。

💡 关于高频访问与特殊需求：
如果你的二创项目（如大型活动应援、科研分析）确实需要远超常规额度的调用频次，请务必提前联系维护团队。我们非常乐意与你沟通，共同商讨定制化的技术优化方案（如数据打包分发等），在不击穿项目方自费服务器带宽的前提下，共同为二创生态保驾护航。
