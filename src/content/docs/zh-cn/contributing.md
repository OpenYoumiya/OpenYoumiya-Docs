OpenYoumiya 采用异步、公开的社区协作模式。这个项目由热爱驱动，但也离不开每一位开发者的共同维护。无论是修复一个数据错漏、提交一段核心代码，还是完善一篇文档，你的贡献都能让二创生态变得更好。

你可以通过以下几种方式参与到 OpenYoumiya 的建设中：

## 🛠️ 如何参与贡献

### 1. 数据考据与报错

如果你在开发或使用过程中，发现 OpenYoumiya API 返回的数据有误（例如歌单错漏、声优归属不正确、Live 场馆信息不全等）：

- 请前往 [GitHub Issues](https://github.com/OpenYoumiya/OpenYoumiya-Docs/issues) 提交 Bug 反馈。
- 专业提示：提交时若能附带官方推特、官网公告或 Live 报告等权威考据链接，将极大加快我们的审核与修正速度。

### 2. 功能提案与模型扩展

如果你希望 OpenYoumiya 支持新的核心模型（如加入新的企划、扩展某种衍生关系等），或者对 API 架构有更好的想法：

- 欢迎在 [GitHub Discussions](https://github.com/OpenYoumiya/OpenYoumiya-Docs/discussions)中开启新话题。
- 在正式提交 PR 之前，建议先通过 Discussion 与维护团队沟通设计思路，避免重复劳动。

### 3. 代码与文档贡献

我们非常欢迎关于 API 性能优化、边缘case处理、甚至文档错别字修正的 Pull Request（PR）：

- 请遵循现有的代码规范与 通用规范。
- 提交 PR 时，请简要说明修改原因及影响范围，以便我们进行 Code Review。

## 💬 联系我们与社区互动

如果你的问题带有私密性，或涉及不适合在公开社区讨论的事务，可以通过以下渠道与我们取得直接联系：
