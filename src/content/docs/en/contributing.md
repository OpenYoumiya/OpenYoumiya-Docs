OpenYoumiya uses an asynchronous, public community collaboration model. The project is driven by passion, but it also depends on shared maintenance from developers and researchers. Whether you fix a data issue, submit core code, or improve a document, your contribution helps make the fan-creation ecosystem better.

You can participate in OpenYoumiya in the following ways:

## How to contribute

### 1. Data research and corrections

If you find incorrect data while developing or using OpenYoumiya API, such as missing setlist entries, incorrect seiyuu relationships, or incomplete live venue information:

- Open a bug report in [GitHub Issues](https://github.com/OpenYoumiya/OpenYoumiya-Docs/issues).
- Tip: including authoritative research links such as official posts, official website announcements, or live reports will greatly speed up review and correction.

### 2. Feature proposals and model extensions

If you want OpenYoumiya to support a new core model, add a new project, extend a derivative relationship, or improve the API architecture:

- Start a topic in [GitHub Discussions](https://github.com/OpenYoumiya/OpenYoumiya-Docs/discussions).
- Before submitting a PR, discuss the design with the maintenance team to avoid duplicated work.

### 3. Code and documentation contributions

Pull requests are welcome for API performance improvements, edge-case handling, documentation typo fixes, and related work:

- Follow the existing code style and common specifications.
- When submitting a PR, briefly explain why the change is needed and what scope it affects so the maintainers can review it efficiently.
