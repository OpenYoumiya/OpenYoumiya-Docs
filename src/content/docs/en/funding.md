OpenYoumiya API is kept freely available as infrastructure for the fan-creation community. Anyone can use it for free within the documented rate limits.

As a project started and maintained by community fans at personal cost, reliable delivery depends on very real ongoing expenses. These include server scaling, high-bandwidth traffic, database backups and hosting, monitoring and auditing, and the daily cost of careful data research and maintenance.

The world keeps changing, and no one can predict how long any particular feeling will last. While we still care, we want to preserve the best memories and most sincere passion around these works in a data universe that can last longer than any single moment.

If OpenYoumiya API has helped your project, you can support ongoing operations through the channel below. Every contribution helps keep this virtual stage online and healthy.

## Sponsorship channels

- Afdian: [https://ifdian.net/a/OpenYoumiya](https://ifdian.net/a/OpenYoumiya)

Sponsorship will be used for public API stability, global acceleration gateway traffic, and ongoing expansion of documentation and datasets.

All sponsors who help power the project will be permanently recorded on the project's acknowledgements wall.

Thank you for helping us build a stronger foundation for the fan-creation ecosystem.
