OpenYoumiya exposes public data through the OpenAPI Gateway:

```http
https://open.youmiya.love/api/v1
```

The live OpenAPI document is generated by Gateway:

```http
https://open.youmiya.love/openapi.json
```

Gateway receives the full internal Origin contract from `Origin /origin/openapi.json`, applies the public allowlist, and exposes only routes intended for third-party API consumers.

## Current public routes

| Method | Path | Description |
| :--- | :--- | :--- |
| `GET` | `/api/v1/healthz` | Health check. |
| `GET` | `/api/v1/projects` | List projects. |
| `GET` | `/api/v1/projects/{key}` | Get one project. |
| `GET` | `/api/v1/franchises` | List franchises. |
| `GET` | `/api/v1/groups` | List groups. |
| `GET` | `/api/v1/project-groups` | List project/group relations. |
| `GET` | `/api/v1/characters` | List characters. |
| `GET` | `/api/v1/seiyuus` | List seiyuus. |
| `GET` | `/api/v1/casts` | List cast relations. |
| `GET` | `/api/v1/venues` | List venues. |

All routes except health checks require:

```http
Authorization: Bearer <OPENYOUMIYA_API_TOKEN>
```
